## WHO I AM 🤔

I am a backend-focused software engineer passionate about building **scalable, reliable, and maintainable software systems**.

I develop backend applications and RESTful services using **ASP.NET Core, Spring Boot, Flask, and FastAPI**. I am continuously improving my knowledge of **database technologies, software architecture, API development, and high-performance systems**.

I believe software development is not only about writing code that works. I aim to build solutions that are **clean, testable, maintainable, and easy to improve over time**. For this reason, I pay close attention to software engineering principles such as **SOLID, Clean Code, design patterns, and layered architecture**.

I combine my backend development skills with artificial intelligence technologies by building applications that integrate **Large Language Models, AI services, and intelligent automation into backend systems**.

I enjoy learning new technologies, transforming ideas into working products, and developing software solutions that create meaningful value for real-world problems.

I am especially interested in building **secure, scalable, and high-performance systems for the finance and banking industries**.

I am open to opportunities as a **Junior Backend Developer, AI Backend Developer, or Software Engineer**, as well as collaborating on innovative software projects.
